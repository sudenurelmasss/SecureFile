\# SecureFile



SecureFile is a Python-based desktop application developed for secure file encryption and decryption through a simple and user-friendly interface.



\## Features



\- Secure file encryption and decryption

\- Password-based encryption

\- Password strength control

\- File selection through a graphical interface

\- Error handling for incorrect passwords or invalid files

\- Modern desktop user interface

\- Local file processing without requiring a server



\## Technologies



\- Python

\- CustomTkinter

\- Cryptography

\- Fernet Encryption

\- Password-Based Key Derivation
